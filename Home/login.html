Acerca de Nosotros

Bienvenido a LieDel, una plataforma desarrollada para apoyar a las empresas mediante el análisis inteligente de datos comerciales.

Nuestro sistema permite visualizar

bar_chart Dashboard de indicadores (KPIs)
trending_up Tendencias de ventas
inventory_2 Control de inventario
payments Análisis financiero
description Reportes en PDF y Excel
warning Productos con stock crítico
storefront Análisis por sucursales y almacenes

Misión

Brindar herramientas que faciliten la toma de decisiones mediante el análisis de datos.

Visión

Convertirnos en una plataforma referente para el análisis empresarial.
